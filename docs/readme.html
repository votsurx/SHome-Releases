README — SHome

SHome — приложение для управления умным домом: Tuya, Zigbee (через Zigbee2MQTT), Frigate. Работает локально, без обязательного облака. Поддерживает сцены, таймеры, статистику, уведомления, presence, MQTT.

Версия: 8.6.0 (82600)
Платформа: Android 10+ (minSdk 29)
Разработчик: ArchitectCO
Владелец: votsurX
Лицензия: Проприетарная (см. EULA)

Скачать

  • GitHub Releases (APK, последний релиз).
  • RuStore — скоро.

Установка:

  1. Скачайте APK.
  2. Разрешите установку из неизвестных источников (Настройки Android → Безопасность).
  3. Установите APK.
  4. Откройте SHome → пройдите онбординг.

Возможности

Устройства

  • Tuya: розетки, выключатели, шторы, свет, HVAC, пылесосы. Локально, без облака Tuya.
  • Zigbee: через Zigbee2MQTT. Датчики, лампы, выключатели, реле.
  • Frigate: камеры, детекция объектов (person, car), события, статистика.

Автоматизация

  • Сцены: запуск по времени, событиям, вручную.
  • Таймеры: включение/выключение по расписанию.
  • Presence: «дома / не дома» по геолокации телефона.

Аналитика

  • Статистика: uptime, алерты, действия по устройствам.
  • Энергия: энергопотребление, тарифы, история.
  • События: полный журнал с фильтрами (дата, устройство, тип).

Интеграции

  • Облако: Mail.ru Cloud — зашифрованные бэкапы (опционально).
  • Уведомления: VK, SMS. С расписанием и cooldown.
  • MQTT: подключение к брокеру (Mosquitto и др.).

Интерфейс

  • Главный экран: адаптивная сетка устройств, фильтр по комнатам.
  • Меню: плитки с возможностью сортировки (long-press).
  • Настройки: сортировка строк (long-press), темы (день/ночь/авто).
  • Screen Saver: Lottie-анимация при простое.
  • Локализация: русский, английский.

Требования

  • Android: 10+ (API 29+).
  • Интернет: опционально (для обновлений, уведомлений, облака).
  • Локальная сеть: для Tuya (LAN), Zigbee (MQTT), Frigate (HTTP).
  • Разрешения: интернет, сеть, геолокация (presence), уведомления (Android 13+).

Первый запуск

  1. Онбординг: приветствие → сканирование устройств → комнаты.
  2. После онбординга — триал 14 дней (snackbar).
  3. Добавьте устройство («+» на главном экране).
  4. Настройте (см. Tuya, Z2M, Frigate).

Лицензия

SHome распространяется в трёх режимах:

  • Демо (бесплатно): 1 устройство, вкл/выкл.
  • Триал (14 дней): все функции, автоматически.
  • Pro (платно, бессрочно): все функции, ключ, привязка к устройству.

Подробнее: Pro-лицензия.

Приватность

  • Данные хранятся локально (SQLite, SecureStorage).
  • androidId — только для привязки Pro-ключа.
  • Геолокация — только для presence, не передаётся.
  • Без Firebase Analytics / Crashlytics.

Подробнее: Политика конфиденциальности.

Архитектура (для разработчиков)

Стек

  • Flutter + Dart 3.
  • Riverpod — управление состоянием.
  • GoRouter — навигация.
  • getIt — DI.
  • sqflite — SQLite.
  • flutter_secure_storage — SecureStorage.

Структура

lib/
├── application/   # провайдеры, модели, сервисы, роутер
├── data/          # БД, протоколы (Tuya, Zigbee), сервисы
├── domain/        # модели, репозитории (интерфейсы)
├── di/            # getIt (DI)
├── presentation/  # экраны, виджеты, тема
├── l10n/          # локализация
