SHome — умный дом без облака

SHome — приложение для управления умным домом: Tuya, Zigbee, Frigate. Работает локально, без обязательного облака. Безопасно, прозрачно, с Pro-лицензией.

Возможности

  • Tuya — розетки, выключатели, шторы, свет, HVAC, пылесосы (локально)
  • Zigbee — через Zigbee2MQTT
  • Frigate — камеры, события, статистика
  • Сцены, таймеры — автоматизация
  • Статистика, энергия — графики, тарифы
  • События — журнал с фильтрами
  • Облако — Mail.ru Cloud (опционально, зашифровано)
  • Уведомления — VK, SMS
  • Presence — «дома / не дома»
  • MQTT — интеграции

Лицензия

Демо — 1 устройство, бесплатно.

Триал — 14 дней полного доступа, автоматически.

Pro — бессрочный ключ, привязка к устройству.
