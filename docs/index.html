SHome

Умный дом без облака. Tuya, Zigbee, Frigate.
Локально. Безопасно. С Pro-лицензией.

⬇ Скачать APK (последний релиз) 📖 Документация

Возможности

🔌 Tuya

Розетки, выключатели, шторы, свет, HVAC, пылесосы. Локально, без облака Tuya.

🐝 Zigbee

Через Zigbee2MQTT. Датчики, лампы, выключатели, реле.

📹 Frigate

Камеры, детекция объектов (person, car), события, статистика.

🎬 Сцены и таймеры

Автоматизация: запуск по времени, событиям, вручную.

📊 Статистика и энергия

Uptime, алерты, действия, энергопотребление, тарифы.

📜 События

Полный журнал с фильтрами по дате, устройству, типу.

☁ Облако

Mail.ru Cloud — зашифрованные бэкапы (опционально).

🔔 Уведомления

VK и SMS. С расписанием и cooldown.

📍 Presence

«Дома / не дома» по геолокации телефона (опционально).

🔗 MQTT

Интеграции с MQTT-брокером (Mosquitto и др.).

🔒 Локально

Данные на вашем устройстве. Без обязательного облака.

🚫 Без рекламы

Никакой рекламы, Firebase Analytics, Crashlytics.
