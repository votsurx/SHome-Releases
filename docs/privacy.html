Политика конфиденциальности SHome

Версия приложения: 8.6.0
Последнее обновление: 25 Ноября 2026

1. Общие положения

Настоящая Политика конфиденциальности описывает, какие данные собирает, использует и хранит приложение SHome («Приложение»), а также ваши права в отношении этих данных.

Мы не продаём ваши данные третьим лицам.

2. Какие данные мы обрабатываем

2.1. Данные устройств умного дома

  • IP-адреса устройств (Tuya, Zigbee, Frigate)
  • Local Key (ключи шифрования Tuya) — в зашифрованном виде
  • Состояние устройств (вкл/выкл, температура, яркость и т.д.)
  • Названия устройств и комнат
  • DPS-параметры устройств
  • friendly_name Zigbee-устройств

2.2. Данные лицензирования Pro

  • androidId — уникальный идентификатор Android-устройства. Используется только для привязки Pro-лицензии к устройству.
  • Лицензионный ключ — сохраняется в зашифрованном виде (SecureStorage).
  • Дата активации Pro — для проверки срока действия.
  • Дата первого запуска триала — для отслеживания 14-дневного пробного периода.
  • Дата последнего запуска — для защиты от отката системных часов.

2.3. Геолокация (опционально)

  • Координаты устройства (широта, долгота) — только если вы включили функцию «Присутствие».
  • Радиус «дома» — задаётся вами.

Геолокация используется исключительно для определения статуса «дома / не дома / рядом» и автоматизаций. Не передаётся разработчику или третьим лицам.

2.4. Данные для уведомлений (опционально)

  • VK-токен и user ID — для отправки уведомлений в VK.
  • Номер телефона — для отправки SMS-уведомлений.

2.5. Данные для облачного резервного копирования (опционально)

  • Логин и пароль Mail.ru Cloud — для загрузки/скачивания зашифрованных бэкапов.
  • Пароль хранится в зашифрованном виде (SecureStorage).

2.6. Технические данные

  • Версия приложения
  • Модель устройства (телефона)
  • Версия операционной системы
  • Логи ошибок (локально, через Talker)

3. Как мы используем данные

  • Для управления устройствами умного дома
  • Для активации и проверки Pro-лицензии
  • Для определения присутствия (если включено)
  • Для отправки уведомлений (если настроено)
  • Для резервного копирования (если настроено)
  • Для исправления ошибок

4. Хранение данных

  • Локально на устройстве пользователя (SQLite, SecureStorage).
  • В зашифрованном виде (AES-256 для SecureStorage).
  • Данные не передаются на серверы разработчика.
  • Данные передаются только тем сервисам, которые явно настроены пользователем (см. раздел 5).

5. Сторонние сервисы

Приложение может взаимодействовать со следующими сторонними сервисами по вашему выбору:

5.1. Tuya (умные устройства)

  • Что передаётся: идентификатор устройства, IP-адрес, статус.
  • Куда: локально (LAN) или через Tuya Cloud (если настроено).
  • Политика: https://www.tuya.com/privacy

5.2. Zigbee2MQTT (Zigbee-устройства)

  • Что передаётся: MQTT-сообщения с состоянием устройств.
  • Куда: ваш MQTT-брокер (локально или удалённо).
  • Политика: зависит от вашего брокера.

5.3. Frigate (видеонаблюдение)

  • Что передаётся: события детекции (person, car), статистика.
  • Куда: ваш сервер Frigate (локально или удалённо).
  • Политика: зависит от вашего сервера.

5.4. Mail.ru Cloud (резервное копирование)

  • Что передаётся: зашифрованный файл конфигурации.
  • Куда: Mail.ru Cloud.
  • Политика: https://help.mail.ru/cloud/legal/privacy

5.5. VK (уведомления)

  • Что передаётся: текст уведомления, ваш VK user ID.
  • Куда: VK API.
  • Политика: https://vk.com/privacy

5.6. SMS-шлюз (уведомления)

  • Что передаётся: текст SMS, номер телефона.
  • Куда: через SMS-шлюз вашего оператора.
  • Политика: зависит от оператора.

5.7. GitHub (обновления)

  • Что передаётся: версия приложения (для проверки обновлений).
  • Куда: GitHub API.
  • Политика: https://docs.github.com/en/site-policy/privacy-policies

6. Безопасность

  • Шифрование данных (AES-256, SecureStorage)
  • Безопасные протоколы передачи (HTTPS, MQTT over TLS — если настроено)
  • Регулярные обновления безопасности
  • Локальное хранение (без облачных сервисов разработчика)

7. Аналитика и crash-логи

Мы не используем Firebase Analytics, Crashlytics или иные внешние сервисы аналитики.

Логи ошибок хранятся локально на устройстве (через Talker) и не передаются разработчику. Вы можете просмотреть их в настройках приложения.

8. Права пользователя

  • Получить копию своих данных (экспорт конфигурации в настройках).
  • Удалить данные (удаление приложения = удаление всех локальных данных).
  • Отозвать согласие (удаление приложения).
  • Отключить геолокацию, уведомления, облако — в настройках приложения.
  • Обратиться с жалобой в Роскомнадзор (https://rkn.gov.ru).

9. Данные детей

Приложение не предназначено для детей младше 13 лет. Мы сознательно не собираем данные детей.

10. Согласие на обработку

Используя приложение, вы даёте согласие на обработку следующих данных:

  • androidId (для лицензирования Pro)
  • Геолокация (для presence, если включено)
  • Логин/пароль Mail.ru Cloud (для бэкапов, если настроено)
  • VK-токен (для уведомлений, если настроено)
  • Номер телефона (для SMS, если настроено)
  • IP-адреса устройств (для управления)

Согласие действует до удаления приложения. Вы можете отозвать согласие, удалив приложение.

11. Изменения политики

Мы можем обновлять политику. О значительных изменениях будем уведомлять в приложении. Дата последнего обновления указана в начале документа.

SHome Privacy Policy

App version: 8.6.0
Last updated: November 25, 2026

1. General

This Privacy Policy describes what data the SHome application (the “App”) collects, uses, and stores, as well as your rights regarding this data.

We do not sell your data to third parties.

2. Data we process

2.1. Smart home device data

  • Device IP addresses (Tuya, Zigbee, Frigate)
  • Local Keys (Tuya encryption keys) — encrypted
  • Device state (on/off, temperature, brightness, etc.)
  • Device and room names
  • Device DPS parameters
  • Zigbee device friendly_name

2.2. Pro licensing data

  • androidId — unique Android device identifier. Used only to bind a Pro license to the device.
  • License key — stored encrypted (SecureStorage).
  • Pro activation date — to verify the license validity.
  • Trial start date — to track the 14-day trial period.
  • Last seen date — to protect against system clock rollback.

2.3. Geolocation (optional)

  • Device coordinates (latitude, longitude) — only if you enable the “Presence” feature.
  • Home radius — set by you.

Geolocation is used solely to determine “home / away / near” status for automations. It is not transmitted to the developer or third parties.

2.4. Notification data (optional)

  • VK token and user ID — to send VK notifications.
  • Phone number — to send SMS notifications.

2.5. Cloud backup data (optional)

  • Mail.ru Cloud login and password — to upload/download encrypted backups.
  • Password is stored encrypted (SecureStorage).

2.6. Technical data

  • App version
  • Device model
  • Operating system version
  • Error logs (locally, via Talker)

3. How we use data

  • To control smart home devices
  • To activate and verify the Pro license
  • To determine presence (if enabled)
  • To send notifications (if configured)
  • To perform backups (if configured)
  • To fix errors

4. Data storage

  • Locally on the user's device (SQLite, SecureStorage).
  • Encrypted (AES-256 for SecureStorage).
  • Data is not transmitted to the developer's servers.
  • Data is transmitted only to services explicitly configured by the user (see Section 5).

5. Third-party services

The App may interact with the following third-party services at your choice:

5.1. Tuya (smart devices)

  • Data transmitted: device ID, IP address, status.
  • Destination: locally (LAN) or via Tuya Cloud (if configured).
  • Policy: https://www.tuya.com/privacy

5.2. Zigbee2MQTT (Zigbee devices)

  • Data transmitted: MQTT messages with device state.
  • Destination: your MQTT broker (local or remote).
  • Policy: depends on your broker.

5.3. Frigate (video surveillance)

  • Data transmitted: detection events (person, car), statistics.
  • Destination: your Frigate server (local or remote).
  • Policy: depends on your server.

5.4. Mail.ru Cloud (backup)

  • Data transmitted: encrypted configuration file.
  • Destination: Mail.ru Cloud.
  • Policy: https://help.mail.ru/cloud/legal/privacy

5.5. VK (notifications)

  • Data transmitted: notification text, your VK user ID.
  • Destination: VK API.
  • Policy: https://vk.com/privacy

5.6. SMS gateway (notifications)

  • Data transmitted: SMS text, phone number.
  • Destination: via your carrier's SMS gateway.
  • Policy: depends on the carrier.

5.7. GitHub (updates)

  • Data transmitted: app version (to check for updates).
  • Destination: GitHub API.
  • Policy: https://docs.github.com/en/site-policy/privacy-policies

6. Security

  • Data encryption (AES-256, SecureStorage)
  • Secure transmission protocols (HTTPS, MQTT over TLS — if configured)
  • Regular security updates
  • Local storage (no developer cloud services)

7. Analytics and crash logs

We do not use Firebase Analytics, Crashlytics, or other external analytics services.

Error logs are stored locally on the device (via Talker) and are not transmitted to the developer. You can view them in the App settings.

8. User rights

  • Obtain a copy of your data (export configuration in settings).
  • Delete your data (uninstalling the App removes all local data).
  • Withdraw consent (uninstall the App).
  • Disable geolocation, notifications, cloud — in the App settings.
  • Submit a complaint to Roskomnadzor (https://rkn.gov.ru).

9. Children's data

The App is not intended for children under 13. We do not knowingly collect children's data.

10. Consent to processing

By using the App, you consent to the processing of the following data:

  • androidId (for Pro licensing)
  • Geolocation (for presence, if enabled)
  • Mail.ru Cloud login/password (for backups, if configured)
  • VK token (for notifications, if configured)
  • Phone number (for SMS, if configured)
  • Device IP addresses (for control)

Consent is valid until the App is uninstalled. You can withdraw consent by uninstalling the App.

11. Changes to this policy

We may update this policy. We will notify users in the App about significant changes. The last updated date is shown at the beginning of this document.

12. Contact

For privacy questions, contact: votsurx@gmail.com
