# Философия SHome ## 1. Локально — значит безопасно SHome не отправляет данные на наши серверы. Все устройства, комнаты, сцены, статистика, настройки хранятся **на вашем устройстве** (SQLite, SecureStorage). Облако (Mail.ru) — **опционально** и только для резервных копий, **зашифрованных** вашим ключом. ## 2. Без обязательного облака Большинство «умных домов» требуют аккаунт в облаке, подписку и постоянный интернет. SHome работает **локально**: Tuya — по LAN, Zigbee — через ваш Z2M, Frigate — через ваш сервер. Интернет нужен только для: - проверки обновлений (опционально); - уведомлений VK/SMS (опционально); - облачных бэкапов (опционально). ## 3. Открытость и предсказуемость - **Открытый код** (частично) — вы можете проверить, что приложение делает. - **Прозрачные разрешения** — приложение не просит больше, чем нужно. - **Прозрачная лицензия** — Pro активируется **offline-ключом**, без привязки к аккаунту. ## 4. Pro — за развитие, а не за «отключение боли» Демо-режим **не мешает** пользоваться базовым функционалом (1 устройство). Pro открывает **дополнительные** возможности (сцены, статистика, Zigbee, Frigate, облако), а не «отключает рекламу» или «разблокирует то, что должно быть бесплатно». Мы верим: **платить нужно за ценность**, а не за отсутствие ограничений. ## 5. Без рекламы и трекинга SHome **не показывает рекламу**, **не использует Firebase Analytics / Crashlytics**, **не передаёт данные третьим лицам** (кроме сервисов, которые вы **явно** настроили: VK, Mail.ru, MQTT-брокер, Frigate). ## 6. Уважение к пользователю - **Нет навязчивых подписок** — Pro покупается один раз (бессрочный ключ). - **Нет «тёмных паттернов»** — paywall честно говорит, что доступно в Pro. - **Нет сбора данных** — даже `androidId` используется **только** для привязки ключа. ## 7. Российский контекст - Приложение **адаптировано** под российские сервисы: Mail.ru Cloud, VK, SMS. - Оплата Pro — через **Telegram-бот** (Stars / ЮKassa), **без** Google Play / App Store. - Публикация — **RuStore** + GitHub Releases (для энтузиастов).
