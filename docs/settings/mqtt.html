Настройка MQTT-брокера

MQTT — протокол обмена сообщениями, который SHome использует для связи с Zigbee2MQTT и Frigate. Вам нужен MQTT-брокер (сервер), к которому подключатся и SHome, и Z2M/Frigate.

Схема: SHome ← MQTT → Zigbee2MQTT / Frigate

Что нужно

  • Сервер: Raspberry Pi, Intel NUC, Synology, мини-ПК (или тот же, где Z2M/Frigate).
  • Docker (рекомендую) или нативная установка.
  • Свободный порт 1883 (MQTT) и 9001 (WebSocket, опционально).

Шаг 1. Установить Mosquitto (Docker)

Mosquitto — самый популярный MQTT-брокер. Установка через Docker:

docker run -d \
  --name mosquitto \
  --restart=unless-stopped \
  -p 1883:1883 \
  -p 9001:9001 \
  -v /opt/mosquitto/config:/mosquitto/config \
  -v /opt/mosquitto/data:/mosquitto/data \
  -v /opt/mosquitto/log:/mosquitto/log \
  eclipse-mosquitto

Создайте папки:

mkdir -p /opt/mosquitto/{config,data,log}

Шаг 2. Настроить mosquitto.conf

Файл: /opt/mosquitto/config/mosquitto.conf:

# Основной listener
listener 1883
protocol mqtt

# WebSocket (для веб-клиентов, опционально)
listener 9001
protocol websockets

# Аутентификация
allow_anonymous false
password_file /mosquitto/config/passwd

# Логи
log_dest file /mosquitto/log/mosquitto.log
log_type error
log_type warning
log_type notice
log_type information

Шаг 3. Создать пользователя

Создайте файл passwd с пользователем:

docker exec -it mosquitto mosquitto_passwd -c /mosquitto/config/passwd your_user

Введите пароль (дважды). Файл passwd создастся с хешем пароля.

Добавить ещё пользователя:

docker exec -it mosquitto mosquitto_passwd /mosquitto/config/passwd another_user

(без -c, чтобы не перезаписать файл)

Шаг 4. Перезапустить Mosquitto

docker restart mosquitto

Проверьте логи:

docker logs -f mosquitto

Должно быть:

mosquitto version 2.x.x starting
Opening ipv4 listen socket on port 1883.
Opening websockets listen socket on port 9001.

Шаг 5. Проверить подключение

Через mosquitto_pub / mosquitto_sub (CLI)

# Подписаться на топик
docker exec -it mosquitto mosquitto_sub -h localhost -u your_user -P your_password -t "test/topic"

# В другом терминале — опубликовать
docker exec -it mosquitto mosquitto_pub -h localhost -u your_user -P your_password -t "test/topic" -m "Hello SHome"

Через MQTT Explorer (GUI)

  1. Скачайте MQTT Explorer.
  2. Подключитесь: your-server:1883, логин/пароль.
  3. Опубликуйте тестовое сообщение → проверьте, что оно приходит.

Шаг 6. Настроить SHome

  1. Откройте SHome → Настройки → MQTT.
  2. Введите:
    • URL: mqtt://your-server:1883
    • Логин: your_user
    • Пароль: your_password
  3. Сохраните. SHome подключится к брокеру.

Шаг 7. Проверить в SHome

  • Меню → Zigbee → «Сканировать» — SHome получит список устройств (если Z2M настроен).
  • Меню → Frigate — SHome получит камеры (если Frigate настроен).

Безопасность (рекомендую)

1. Не используйте allow_anonymous true

Всегда создавайте пользователя и пароль.

2. Ограничьте доступ по IP

В mosquitto.conf:

listener 1883
allow_anonymous false
password_file /mosquitto/config/passwd

# Разрешить только локальную сеть
# (если брокер в той же сети, что SHome)
# Используйте firewall (ufw / iptables) для ограничения

3. TLS (опционально)

Для шифрования трафика:

listener 8883
protocol mqtt
cafile /mosquitto/config/ca.crt
certfile /mosquitto/config/server.crt
keyfile /mosquitto/config/server.key
require_certificate false

В SHome: mqtts://your-server:8883 (с TLS).

4. Firewall

Откройте порт 1883 только для локальной сети:

sudo ufw allow from 192.168.0.0/16 to any port 1883

Частые проблемы

SHome не подключается к MQTT

  • Проверьте URL: mqtt://your-server:1883 (не http://!).
  • Проверьте логин/пароль.
  • Проверьте, что порт 1883 открыт (firewall).
  • Проверьте логи Mosquitto: docker logs mosquitto.

«Connection refused»

  • Mosquitto запущен? docker ps | grep mosquitto.
  • Порт 1883 слушается? netstat -tlnp | grep 1883.
  • Firewall блокирует? Проверьте ufw status.

«Not authorized»

  • Пользователь создан? docker exec -it mosquitto cat /mosquitto/config/passwd.
  • Пароль верный? Пересоздайте: mosquitto_passwd -c ....
  • allow_anonymous false в конфиге?

Z2M / Frigate не подключаются к MQTT

  • Проверьте mqtt.server в конфиге Z2M / Frigate.
  • Проверьте логин/пароль (те же, что в SHome).
  • Проверьте, что Z2M / Frigate в той же сети, что MQTT-брокер.

Сообщения не доходят

  • Проверьте топики (MQTT Explorer).
  • Проверьте QoS (0, 1, 2).
  • Проверьте retain-флаг.
