Уведомления (VK / SMS)

SHome может отправлять уведомления о событиях (алерты, offline, сцены, Frigate, Zigbee) в VK и по SMS. Это опционально — работает только если настроено.

Схема: SHome → VK API / SMS-шлюз → ваше устройство

Что нужно

  • VK: аккаунт VK, Standalone-приложение (для access_token).
  • SMS: SMS-шлюз с API (например, SMS.ru, Twilio) или встроенный SMS-сервис телефона.
  • Функция доступна в Pro (после триала).

Часть 1. VK-уведомления

Шаг 1. Создать Standalone-приложение VK

  1. Откройте vk.com/dev → «Мои приложения».
  2. Нажмите «Создать приложение».
  3. Выберите тип «Standalone-приложение».
  4. Название: SHome.
  5. Подтвердите.

Шаг 2. Получить access_token

Есть два способа:

Способ A: Implicit Flow (через браузер)

  1. В настройках приложения VK найдите ID приложения (например, 12345678).
  2. Откройте в браузере URL: 
    https://oauth.vk.com/authorize?client_id=ВАШ_APP_ID&display=page&redirect_uri=https://oauth.vk.com/blank.html&scope=messages&response_type=token&v=5.131
    (замените ВАШ_APP_ID на ID приложения)
  3. Разрешите доступ.
  4. Вас перебросит на https://oauth.vk.com/blank.html#access_token=...&expires_in=...&user_id=....
  5. Скопируйте access_token (длинная строка) и user_id.

Способ B: Сервисный ключ (для сообществ)

Если у вас есть сообщество VK:

  1. Управление сообществом → Работа с API → Создать ключ.
  2. Выберите права: messages, manage.
  3. Скопируйте сервисный ключ и ID сообщества.

Шаг 3. Настроить VK в SHome

  1. Откройте SHome → Настройки → Уведомления.
  2. Включите «Уведомления включены».
  3. Включите «VK».
  4. Введите:
    • VK Token: access_token из шага 2.
    • VK User ID: ваш user_id (число).
  5. Сохраните.

Шаг 4. Настроить типы уведомлений

В разделе «Уведомления» → «Типы»:

  • Сцены — уведомления при выполнении сцен.
  • Устройства — вкл/выкл, изменения состояния.
  • Алерты — вода, дым, газ, движение, контакт (Zigbee).
  • Ошибки — offline, online, ошибки подключения.
  • Zigbee — water_leak, smoke, gas, motion, contact.
  • Frigate — person, car, dog, cat, bird.
  • Offline — Zigbee offline, Frigate offline.

Шаг 5. Проверить

  1. Нажмите «Тест» (если есть) — SHome отправит тестовое сообщение в VK.
  2. Или вызовите событие (вкл/выкл устройство, алерт) — проверьте, что уведомление пришло.

Если уведомления не приходят — проверьте access_token (не истёк?), user_id, права приложения (messages).

Часть 2. SMS-уведомления

Шаг 1. Выбрать SMS-шлюз

Варианты:

  • SMS.ru — российский, API, доступные цены.
  • Twilio — международный, надёжный.
  • Встроенный SMS — через SIM-карту телефона (бесплатно, но только с телефона).

Шаг 2. Настроить SMS.ru (пример)

  1. Зарегистрируйтесь на sms.ru.
  2. Пополните баланс (от 100 ₽).
  3. Получите API-ключ в личном кабинете.

Шаг 3. Настроить SMS в SHome

  1. Откройте SHome → Настройки → Уведомления.
  2. Включите «SMS».
  3. Введите:
    • Номер телефона: ваш номер (например, +79001234567).
    • API-ключ (если требуется): из SMS.ru / Twilio.
  4. Сохраните.

Внимание: SMS-шлюз платный (за каждое сообщение). Убедитесь, что баланс пополнен.

Шаг 4. Настроить типы уведомлений

Аналогично VK (см. выше). По умолчанию SMS только для алертов (вода, дым, газ) — чтобы не тратить деньги на всё подряд.

Шаг 5. Проверить

  1. Нажмите «Тест SMS» (если есть).
  2. Или вызовите алерт — проверьте, что SMS пришло.

Расписание уведомлений

Чтобы не получать уведомления ночью — настройте расписание:

  1. В разделе «Уведомления» → «Расписание».
  2. Включите «Использовать расписание».
  3. Задайте:
    • С: 09:00
    • По: 21:00
    • Дни недели: Пн–Вс (или выборочно).
  4. Опция «Только алерты» — если включена, вне расписания приходят только алерты (вода, дым, газ), остальное — подавляется.

Cooldown (защита от спама)

Чтобы не получать 100 одинаковых уведомлений — настройте cooldown:

  1. В разделе «Уведомления» → «Cooldown».
  2. Задайте минуты: например, 5 — повторное уведомление того же типа не отправится в течение 5 минут.

Частые проблемы

VK: «Не удалось отправить»

  • access_token истёк — получите новый (Implicit Flow).
  • user_id неверный — проверьте (число).
  • Приложение VK не имеет прав messages — пересоздайте.
  • VK API недоступен — попробуйте позже.

VK: «Forbidden»

  • Пользователь запретил сообщения от приложения — разрешите в настройках VK.
  • Приложение заблокировано VK — проверьте статус.

SMS: «Не удалось отправить»

  • API-ключ неверный — проверьте в личном кабинете SMS.ru.
  • Баланс SMS.ru = 0 — пополните.
  • Номер неверный — проверьте формат (+79001234567).

Уведомления не приходят вообще

  • «Уведомления включены» = true?
  • Типы уведомлений включены (сцены, алерты и т.д.)?
  • Расписание не блокирует? (если «только алерты» — обычные уведомления не придут вне расписания).
  • Cooldown не подавляет? (проверьте 5 мин).

Слишком много уведомлений

  • Увеличьте cooldown (10–30 мин).
  • Отключите лишние типы (например, «устройства»).
  • Включите расписание (ночь — тишина).
