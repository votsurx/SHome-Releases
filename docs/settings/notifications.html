VK: Создать Standalone-приложение в vk.com/dev → получить access_token (через Implicit Flow). Или использовать сервисный ключ + user_id. В SHome: Настройки → Уведомления → VK → токен + user ID. SMS: SMS-уведомления работают на штатной сим-арте устройства на котором установлено приложение. В SHome: Настройки → Уведомления → SMS → номер.
