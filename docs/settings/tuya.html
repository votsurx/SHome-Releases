Настройка Tuya

Tuya-устройства (розетки, выключатели, шторы, свет, HVAC, пылесосы) работают в SHome локально — по LAN, без облака Tuya. Для этого нужны deviceId и localKey.

Важно: SHome общается с Tuya-устройствами напрямую по локальной сети (порт 6668). Устройство и телефон должны быть в одной сети.

Что нужно

  • Tuya-устройство, добавленное в приложение Tuya Smart или Smart Life.
  • Аккаунт Tuya (для получения localKey).
  • Телефон и устройство в одной Wi-Fi сети.

Шаг 1. Получить deviceId

Способ A: приложение Tuya Smart / Smart Life

  1. Откройте приложение Tuya Smart (или Smart Life).
  2. Выберите устройство.
  3. Нажмите на «⋮» (или «Настройки») → «Информация об устройстве».
  4. Скопируйте Device ID (длинная строка вида bf1234567890abcdef).

Способ B: Tuya IoT Platform

  1. Зарегистрируйтесь на iot.tuya.com.
  2. Создайте Cloud Project (Data Center — выберите ближайший, например «Central Europe»).
  3. В проекте: Devices → Link Tuya App Account → отсканируйте QR-код из приложения Tuya Smart (Настройки → Аккаунт → «Link Tuya App Account»).
  4. После привязки: Devices → выберите устройство → Device ID.

Шаг 2. Получить localKey

Способ A: Tuya IoT Platform (рекомендую)

  1. В iot.tuya.com → ваш проект → Devices.
  2. Выберите устройство → Device Details.
  3. Найдите поле Local Key — это и есть localKey (16 символов, буквы и цифры).

Способ B: tinytuya (CLI)

  1. Установите Python 3.8+.
  2. Установите tinytuya: 
    pip install tinytuya
  3. Запустите мастер: 
    python -m tinytuya wizard
  4. Введите API Key и API Secret из Tuya IoT Platform (Project → Overview → Access ID/Secret).
  5. Мастер просканирует сеть и выдаст файл devices.json с id, key (localKey), ip.

Способ C: сканер SHome

SHome имеет встроенный сканер Tuya (меню → «Сканер Tuya»). Если устройство в сети, SHome может получить localKey автоматически (если устройство поддерживает Tuya 3.3+ и ещё не привязано к другому аккаунту).

Совет: если localKey не подходит — перепривяжите устройство в Tuya Smart (удалить → добавить заново). После перепривязки localKey меняется.

Шаг 3. Добавить устройство в SHome

  1. Откройте SHome → главный экран → «+» (Floating Action Button).
  2. Заполните:
    • Название — любое (например, «Розетка в спальне»).
    • Тип устройства — розетка / выключатель / штора / свет / HVAC / пылесос.
    • Device ID — из шага 1.
    • Local Key — из шага 2.
    • IP-адрес — опционально (если не указан, SHome найдёт по LAN).
  3. Нажмите «Добавить».
  4. Устройство появится на главном экране. Проверьте вкл/выкл.

Шаг 4. Проверить

  • Устройство online (зелёная точка).
  • Вкл/выкл работает.
  • Если устройство offline — см. «Частые проблемы».

Частые проблемы

Устройство offline

  • Проверьте, что телефон и устройство в одной Wi-Fi сети.
  • Проверьте IP-адрес устройства (сканер сети, роутер).
  • Проверьте firewall на роутере (порт 6668).
  • Перезагрузите устройство (выключите/включите питание).

localKey не подходит

  • localKey меняется при перепривязке устройства в Tuya Smart.
  • Удалите устройство из Tuya Smart и добавьте заново — получите новый localKey.
  • Убедитесь, что не используете localKey от другого устройства.

Устройство Tuya 3.4+ / 3.5

  • Новые устройства Tuya (3.4+) используют protocol 3.4/3.5 — SHome поддерживает (через tinytuya).
  • Если не работает — проверьте версию протокола в Tuya IoT Platform (Device Details → Protocol Version).

«Device ID не найден»

  • Убедитесь, что устройство привязано к аккаунту Tuya.
  • В Tuya IoT Platform: Devices → Link Tuya App Account → привяжите аккаунт.
