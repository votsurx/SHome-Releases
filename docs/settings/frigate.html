Настройка Frigate

Frigate — это NVR (Network Video Recorder) с детекцией объектов в реальном времени (person, car, dog, cat и т.д.). SHome подключается к Frigate и показывает камеры, события, статистику.

Схема: IP-камера (RTSP) → Frigate → MQTT + API → SHome

Что нужно

  • Сервер: Raspberry Pi 4+ (с Coral USB), Intel NUC, Synology, мини-ПК.
  • IP-камеры с RTSP (Hikvision, Dahua, Reolink, Tapo и т.п.).
  • MQTT-брокер: Mosquitto (см. настройку MQTT).
  • Docker + Docker Compose.

Шаг 1. Установить Frigate

Создайте папку для Frigate:

mkdir -p /opt/frigate/config /opt/frigate/media
cd /opt/frigate

docker-compose.yml:

version: '3.9'

services:
  frigate:
    container_name: frigate
    image: ghcr.io/blakeblackshear/frigate:stable
    restart: unless-stopped
    shm_size: "256mb"
    ports:
      - "5000:5000"     # веб-интерфейс
      - "8554:8554"     # RTSP restream
      - "8555:8555"     # WebRTC (если нужно)
    volumes:
      - /etc/localtime:/etc/localtime:ro
      - /opt/frigate/config:/config
      - /opt/frigate/media:/media/frigate
      - type: tmpfs
        target: /tmp/cache
        tmpfs:
          size: 1000000000
    environment:
      FRIGATE_RTSP_PASSWORD: "your_camera_password"
    devices:
      - /dev/bus/usb:/dev/bus/usb   # для Coral USB (если есть)

shm_size: "256mb" — для 1–2 камер. Для 4+ камер увеличьте до 512mb или 1gb.

Coral USB — ускоряет детекцию (опционально, но рекомендуется для 2+ камер).

Шаг 2. Настроить config.yml

Файл: /opt/frigate/config/config.yml:

mqtt:
  host: your-mqtt-broker
  user: your_user
  password: your_password

detectors:
  coral:
    type: edgetpu
    device: usb
  # Или CPU (медленно, для теста):
  # cpu:
  #   type: cpu

cameras:
  front_door:
    ffmpeg:
      inputs:
        - path: rtsp://user:password@camera-ip:554/Streaming/Channels/101
          roles:
            - detect
            - record
    detect:
      width: 1280
      height: 720
      fps: 5
    objects:
      track:
        - person
        - car
        - dog
        - cat
    record:
      enabled: true
      retain:
        days: 7
        mode: motion

  backyard:
    ffmpeg:
      inputs:
        - path: rtsp://user:password@camera-ip-2:554/Streaming/Channels/101
          roles:
            - detect
            - record
    detect:
      width: 1280
      height: 720
      fps: 5
    objects:
      track:
        - person
        - car

RTSP-URL зависит от камеры:

  • Hikvision: rtsp://user:pass@ip:554/Streaming/Channels/101
  • Dahua: rtsp://user:pass@ip:554/cam/realmonitor?channel=1&subtype=0
  • Reolink: rtsp://user:pass@ip:554/h264Preview_01_main
  • Tapo: rtsp://user:pass@ip:554/stream1

Шаг 3. Запустить Frigate

docker compose up -d

Проверьте логи:

docker logs -f frigate

Должно быть:

Frigate started
MQTT connected
Camera front_door: initialized
Detector coral: ready

Откройте веб-интерфейс: http://your-server:5000.

Шаг 4. Настроить SHome

  1. Откройте SHome → Настройки → Frigate.
  2. Введите:
    • URL: http://your-server:5000
    • Логин/пароль (если настроена аутентификация Frigate).
  3. Сохраните.
  4. Откройте Меню → Frigate.
  5. SHome покажет камеры и последние события.

Шаг 5. Настроить уведомления

  1. Настройки → Уведомления → VK (или SMS).
  2. Включите Frigate: person, Frigate: car и т.д.
  3. При детекции SHome отправит уведомление.

Шаг 6. Проверить

  • В SHome: меню → Frigate → камеры (превью).
  • События (person, car) — список.
  • Уведомления приходят.

Частые проблемы

Frigate не запускается

  • Проверьте docker logs frigate — там ошибка.
  • Проверьте config.yml — YAML чувствителен к отступам.
  • Проверьте shm_size — если мало, увеличьте.

Нет событий

  • Проверьте detect в config.yml — камера включена?
  • Проверьте, что объекты в кадре (person, car) — Frigate их видит.
  • Проверьте веб-интерфейс Frigate (:5000) — там видны события?

SHome не подключается к Frigate

  • Проверьте URL (http://your-server:5000).
  • Проверьте firewall (порт 5000).
  • Проверьте, что SHome (телефон) в той же сети, что Frigate.

Уведомления не приходят

  • Проверьте VK-токен / SMS-настройки.
  • Проверьте, что в настройках SHome включены Frigate-уведомления (person, car).
  • Проверьте, что Frigate публикует события в MQTT.

Coral USB не найден

  • Проверьте lsusb — устройство видно?
  • Проверьте права: sudo usermod -a -G dialout $USER.
  • Проверьте, что devices: /dev/bus/usb в docker-compose.yml.
