Присутствие (Presence Detection)

Presence Detection — определение статуса «дома / не дома / рядом» по геолокации телефонов. Используется для автоматизаций (например, «включить свет, когда я дома»).

Важно о приватности: координаты используются для функции Presence. При обычной работе они обрабатываются SHome; если вы отправляете их в приложение через HTTP-интеграцию, они передаются по вашей локальной сети на устройство с SHome. Не открывайте этот HTTP-сервер напрямую в интернет и не настраивайте проброс его порта на роутере.

Что нужно

  • Телефон с GPS и интернетом.
  • Разрешение «Геолокация» (Android: ACCESS_FINE_LOCATION).
  • Разрешение «Фоновый режим» (опционально, для работы в фоне).
  • Функция доступна в Pro (после триала).

Как это работает

  1. Телефон отправляет координаты (широта, долгота) в SHome.
  2. SHome сравнивает с координатами «дома» + радиусом.
  3. Если телефон в радиусе — статус home.
  4. Если вне радиуса + прошло awayTimeout — статус away.
  5. Если рядом с радиусом — статус near.

Координаты, полученные SHome, используются для определения статуса Presence и хранятся локально. Если вы настроили передачу данных через облачную интеграцию или внешний сервис, эти данные могут передаваться выбранному вами получателю. Проверьте настройки и политику этого сервиса.

Шаг 1. Включить геолокацию в Android

  1. Настройки Android → Приложения → SHome → Разрешения.
  2. Включите «Геолокация» → «Разрешить всегда» (или «Только при использовании»).
  3. Опционально: «Фоновая работа» (если хотите, чтобы presence работал в фоне).

Шаг 2. Настроить координаты «дома»

  1. Откройте SHome → Меню → Присутствие.
  2. Включите «Включить присутствие».
  3. Задайте «Координаты дома»:
    • Широта (latitude): например, 55.7558
    • Долгота (longitude): например, 37.6173
  4. Радиус «дома»: например, 100 метров (по умолчанию).
  5. Таймаут «away»: например, 5 минут (сколько ждать перед тем, как считать «не дома»).

Как узнать координаты дома?

  • Откройте Google Maps → найдите свой дом → долгое нажатие → скопируйте координаты.
  • Или на latlong.net.

Шаг 3. Добавить телефоны

Presence работает по телефонам (каждому — свой ID).

  1. В разделе «Присутствие» → «Телефоны».
  2. Нажмите «Добавить телефон».
  3. Заполните:
    • ID телефона: уникальный (например, phone_1).
    • Имя: «Мой телефон».
    • IP-адрес (опционально, если телефон в той же сети).
    • Включён: да.
  4. Сохраните.

Несколько телефонов — presence учитывает все. Если хотя бы один дома — статус home.

Шаг 4. Как телефон отправляет координаты

Есть два способа:

Способ A: приложение SHome на телефоне

Если SHome установлен на телефоне — он сам отправляет координаты (через foreground service). Просто включите presence — и SHome начнёт отслеживать.

Способ B: heartbeat от Companion

Если Companion отправляет heartbeat в SHome, он обращается к HTTP-серверу SHome на порту 7777. Свежий heartbeat показывает, что телефон доступен в локальной сети, и может использоваться Presence как признак нахождения дома. Это не передача GPS-координат. 

POST http://IP-УСТРОЙСТВА-С-SHOME:7777/heartbeat?phoneId=phone_1
Content-Type: application/json

{
  "phoneName": "Мой телефон",
  "status": "home",
  "battery": 85,
  "ssid": "HomeWiFi"
}
Безопасность: heartbeat-сервер принимает запросы без проверки учётных данных. Используйте его только в доверенной локальной сети или через VPN. Не открывайте порт 7777 в интернет и не настраивайте проброс этого порта на роутере.

Шаг 5. Проверить

  1. В разделе «Присутствие» отображается статус (home / away / near).
  2. Проверьте: вы дома → статус home.
  3. Выйдите из радиуса → через awayTimeout статус away.
  4. Вернитесь → статус home.

Использование в автоматизациях

Presence можно использовать в сценах:

  • «Когда я дома» → включить свет, открыть шторы.
  • «Когда я ушёл» → выключить всё, включить охрану.
  • «Когда рядом» → включить свет на улице.

В настройках сцены выберите триггер «Присутствие» → статус (home / away / near).

Приватность

Какие данные используются

  • Координаты (широта и долгота) — когда используется Presence.
  • ID телефона и время получения данных — для сопоставления устройства и актуальности статуса.

Где обрабатываются данные

  • Координаты, полученные приложением, используются SHome для определения статуса Presence.
  • При включённом HTTP-сервере запросы с координатами поступают на устройство с SHome по сети.
  • Если настроена облачная или сторонняя интеграция, данные могут передаваться выбранному пользователем сервису.

Как отключить

  • В SHome: выключить функцию «Присутствие».
  • Отозвать разрешение на геолокацию в настройках Android.
  • Отключить HTTP-сервер Presence, если он включён.
  • Удалить облачные записи отдельно, если вы использовали облачную интеграцию.

Где хранится

  • Локально в SQLite на телефоне.
  • Не передаётся разработчику.
  • Не передаётся третьим лицам.

Как отключить

  • В SHome: «Присутствие» → выключить.
  • Или отозвать разрешение «Геолокация» в настройках Android.
  • Или удалить приложение (все данные удаляются).

Энергопотребление

Presence использует GPS — это расходует батарею. Рекомендации:

  • Используйте «Только при использовании» (не «Всегда»), если не нужен фоновый режим.
  • Увеличьте интервал обновления (например, раз в 5 минут).
  • Используйте Wi-Fi вместо GPS (если телефон в сети — статус home).

Частые проблемы

Статус не меняется

  • Геолокация включена в Android?
  • Координаты «дома» верные?
  • Радиус достаточный? (например, 100 м — может быть мало, увеличьте до 200).
  • Телефон отправляет координаты? (проверьте логи SHome).

«Не могу определить местоположение»

  • GPS выключен — включите в шторке Android.
  • Нет сигнала GPS (в помещении) — выйдите на улицу.
  • Разрешение «Геолокация» не дано — проверьте настройки.

Батарея быстро садится

  • Уменьшите частоту обновления (интервал 10–15 мин).
  • Используйте Wi-Fi вместо GPS.
  • Отключите фоновый режим (если не нужен).

Presence не работает в фоне

  • Android: разрешение «Фоновая работа» включено?
  • Батарея: «Без ограничений» для SHome?
  • Некоторые прошивки (MIUI, EMUI) убивают фоновые приложения — добавьте SHome в исключения.

Несколько телефонов — статус неверный

  • Presence учитывает все телефоны. Если хотя бы один дома — home.
  • Если нужно по-другому — настройте сцены с конкретным телефоном.
