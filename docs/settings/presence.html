Что нужно: телефон с геолокацией, разрешение. Настройка: Меню → Присутствие → добавить телефон (ID, имя, IP) → задать координаты «дома» + радиус → включить. Как работает: телефон отправляет координаты → SHome сравнивает с «домом» → статус home / away / near. Разрешения: ACCESS_FINE_LOCATION (Android).
