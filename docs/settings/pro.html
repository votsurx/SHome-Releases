Pro-лицензия

SHome распространяется в трёх режимах: Демо (бесплатно), Триал (14 дней), Pro (платно, бессрочно).

Кратко: Демо — 1 устройство. Триал — 14 дней полного доступа. Pro — всё, бессрочно, по ключу.

Демо-режим (бесплатно)

Доступен всегда, без регистрации.

  • 1 устройство — первое добавленное.
  • Вкл/выкл устройства.
  • Всё остальное — под замком (paywall).
  • Устройства, добавленные в триале, не удаляются — показываются с замком.

Триал (14 дней)

Активируется автоматически при первом запуске после онбординга.

  • 14 дней полного доступа ко всем функциям.
  • По истечении — переход в демо-режим.
  • Один триал на устройство (привязка к androidId).
  • Защита от отката часов: если время устройства откатили — триал считается истёкшим.
Совет: используйте триал, чтобы протестировать все функции (Zigbee, Frigate, облако) перед покупкой Pro.

Pro (бессрочно)

Активируется лицензионным ключом, который приобретается отдельно.

Что даёт

  • Все функции SHome (см. таблицу выше).
  • Неограниченное количество устройств.
  • Бессрочно (если в ключе не указан срок).
  • Привязка к устройству — ключ работает на одном androidId.

Как активировать

  1. Откройте SHome → Настройки → Pro.
  2. Нажмите «Активировать Pro».
  3. Введите ключ (формат SHOME-PRO-...-...).
  4. Нажмите «Активировать».
  5. Если ключ валиден — статус «Pro активен».

Проверка лицензии

Лицензия проверяется на устройстве, без интернета. SHome проверяет:

  • подпись Ed25519, созданную разработчиком;
  • что лицензия выпущена для SHome;
  • совпадение отпечатка лицензии с текущим устройством;
  • срок действия, если он указан.

Закрытый ключ для выпуска лицензий не входит в приложение. В SHome встроен только открытый ключ, необходимый для проверки подписи.

Код запроса и привязка к устройству

Для выпуска лицензии приложение формирует код запроса с отпечатком устройства. Передайте этот код разработчику или поддержке, чтобы получить подписанную лицензию. Код запроса не содержит сам Android ID.

Важно: лицензия выпускается для конкретного устройства. При смене телефона обратитесь к разработчику или поддержке за переносом или перевыпуском лицензии.

Сохраните полученную строку лицензии в надёжном месте. Если локальные данные приложения будут удалены, её можно будет повторно ввести на том же устройстве. Лицензия для другого устройства не подойдёт.

Возврат средств

  • Возврат регулируется условиями продавца.
  • Ключ считается использованным после активации.
  • Если ключ не активировался (ошибка) — обратитесь к продавцу для замены.

Что будет после триала

  • Автоматический переход в демо-режим.
  • Все функции (кроме 1 устройства) — под замком.
  • Устройства, добавленные в триале, остаются (с замком).
  • Данные (сцены, комнаты, настройки) не удаляются.
  • Вы можете активировать Pro в любой момент — всё вернётся.

FAQ

Можно ли перенести Pro на другой телефон?

Технически — нужен новый ключ (привязка к androidId). Обратитесь к продавцу, объясните ситуацию — возможно, выдадут новый ключ бесплатно (по усмотрению).

Что если я потерял ключ?

Ключ хранится в SecureStorage на устройстве. Если приложение удалено — ключ потерян. Обратитесь к продавцу (с чеком об оплате) — выдадут новый.

Можно ли активировать ключ на нескольких устройствах?

Нет, ключ привязан к одному androidId. Для второго устройства — второй ключ.

Работает ли Pro без интернета?

Да. Проверка ключа — offline (HMAC). Интернет нужен только для покупки и обновлений.

Что если ключ с expiry (сроком)?

Если в ключе указан срок — после истечения Pro переходит в демо. Обычно ключи бессрочные.

Как отключить Pro (для теста)?

В debug-сборке — скрытая кнопка над «SHome» на главном экране (сброс лицензии). В release — нет.

Безопасность

  • Офлайн-проверка подписи Ed25519 — для активации не требуется интернет.
  • Закрытый ключ выпуска хранится у разработчика и не встраивается в приложение.
  • Привязка к отпечатку устройства — скопированная лицензия не предназначена для активации на другом телефоне.
  • Локальное хранение — активированная лицензия сохраняется средствами защищённого хранилища платформы.
