Настройка облака (Mail.ru Cloud)

SHome может сохранять зашифрованные резервные копии в Mail.ru Cloud. Это опционально — приложение полностью работает без облака.

Важно: бэкап шифруется вашим ключом до загрузки. Mail.ru Cloud хранит только зашифрованный файл — без ключа восстановить данные невозможно.

Что нужно

  • Аккаунт Mail.ru (бесплатный).
  • Пароль приложения (не основной пароль!) — создаётся в настройках безопасности Mail.ru.
  • Функция доступна в Pro (после триала).

Шаг 1. Создать пароль приложения

Mail.ru требует отдельный пароль для внешних приложений (SHome). Основной пароль не подойдёт.

  1. Откройте id.mail.ru/security.
  2. Войдите в аккаунт Mail.ru.
  3. Раздел «Пароли для внешних приложений».
  4. Нажмите «Создать пароль».
  5. Выберите тип: «Другое» → введите название SHome.
  6. Скопируйте сгенерированный пароль (16 символов, например abcd efgh ijkl mnop).

Сохраните пароль — Mail.ru показывает его только один раз. Если потеряете — создайте новый.

Шаг 2. Подключить облако в SHome

  1. Откройте SHome → Меню → Облако.
  2. Введите:
    • Логин: ваш email Mail.ru (например, user@mail.ru).
    • Пароль приложения: 16-символьный пароль из шага 1.
  3. Нажмите «Подключить».
  4. SHome проверит подключение (через Mail.ru Cloud API).
  5. Если успешно — статус «Подключено».

Пароль хранится в SecureStorage (AES-256) на устройстве. Не передаётся разработчику.

Шаг 3. Сгенерировать ключ шифрования

Перед первым бэкапом нужно сгенерировать ключ шифрования — он используется для шифрования/дешифрования бэкапов.

  1. В разделе «Облако» → «Ключ бэкапа».
  2. Нажмите «Сгенерировать ключ».
  3. SHome создаст случайный ключ (256 бит) и покажет QR-код.
  4. Сохраните QR-код (скриншот, распечатка) — без него восстановить бэкап невозможно.

Ключ хранится в SecureStorage. Если вы удалите приложение — ключ потеряется. Восстановить бэкап можно только по QR-коду.

Шаг 4. Загрузить бэкап

  1. В разделе «Облако» → «Резервное копирование».
  2. Нажмите «Загрузить бэкап».
  3. SHome:
    • соберёт конфигурацию (устройства, комнаты, сцены, настройки);
    • зашифрует ключом;
    • загрузит в Mail.ru Cloud.
  4. Готово. Дата последней синхронизации отобразится в разделе.

Шаг 5. Восстановить бэкап

  1. В разделе «Облако» → «Резервное копирование».
  2. Нажмите «Скачать бэкап».
  3. SHome покажет список бэкапов (по дате).
  4. Выберите нужный.
  5. SHome:
    • скачает файл;
    • расшифрует ключом;
    • восстановит конфигурацию.
  6. Перезапустите приложение (опционально).

Если ключ потерян — восстановить бэкап невозможно. Файл в облаке зашифрован, без ключа это мусор.

Шаг 6. Импорт ключа по QR-коду

Если вы переустановили приложение (или хотите восстановить на другом устройстве) — нужно импортировать ключ из QR-кода.

  1. В разделе «Облако» → «Ключ бэкапа».
  2. Нажмите «Сканировать QR».
  3. Отсканируйте QR-код (со скриншота или распечатки).
  4. Ключ импортируется в SecureStorage.
  5. Теперь можно скачать бэкап и восстановить.

Безопасность

Что защищено

  • Пароль Mail.ru — хранится в SecureStorage (AES-256).
  • Ключ шифрования — хранится в SecureStorage.
  • Бэкап — шифруется до загрузки (AES-256-GCM).
  • Передача — HTTPS (Mail.ru Cloud API).

Что не защищено

  • Если злоумышленник получил доступ к вашему телефону (разблокирован) — он может использовать сохранённый пароль.
  • Если вы потеряли QR-код — бэкап невосстановим.

Рекомендации

  • Используйте пароль приложения Mail.ru (не основной).
  • Храните QR-код в надёжном месте (не в облаке!).
  • Не делитесь QR-кодом с третьими лицами.
  • Периодически делайте бэкапы (раз в неделю/месяц).

Частые проблемы

«Неверный пароль»

  • Используйте пароль приложения, не основной пароль Mail.ru.
  • Проверьте, что скопировали пароль полностью (16 символов).
  • Создайте новый пароль приложения в id.mail.ru/security.

«Не удалось подключиться»

  • Проверьте интернет на телефоне.
  • Проверьте, что Mail.ru Cloud доступен (не заблокирован).
  • Попробуйте позже (возможны сбои Mail.ru).

«Нет бэкапов»

  • Вы ещё не загружали бэкап — нажмите «Загрузить бэкап».
  • Проверьте, что вошли в тот же аккаунт Mail.ru.
  • Проверьте папку в Mail.ru Cloud (SHome создаёт папку SHome/).

«Ошибка расшифровки»

  • Ключ шифрования не совпадает с тем, которым зашифрован бэкап.
  • Импортируйте правильный QR-код (тот, что был при создании бэкапа).
  • Если ключ потерян — бэкап невосстановим.

«Ключ не найден»

  • Сгенерируйте ключ (раздел «Ключ бэкапа» → «Сгенерировать»).
  • Или импортируйте QR-код (если ключ уже был).
