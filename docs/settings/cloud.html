Что нужно: аккаунт Mail.ru, пароль приложения (не основной!). Шаг 1: создать пароль приложения: id.mail.ru/security → «Пароли для внешних приложений» → «Создать». Скопировать пароль (16 символов). Шаг 2: в SHome: Меню → Облако → логин (your@mail.ru) + пароль приложения → «Подключить». Шаг 3: бэкап: Сгенерировать ключ шифрования (QR-код). «Загрузить бэкап» → зашифрованный файл в Mail.ru Cloud. Частые проблемы: «Неверный пароль» → используйте пароль приложения, не основной. «Нет бэкапов» → проверьте, что загрузили.
