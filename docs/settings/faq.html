Почему приложение не видит устройства Tuya? → проверьте IP, LAN, localKey. Как получить localKey? → Tuya IoT Platform / tinytuya. SHome работает без интернета? → да, локально. Интернет — только для обновлений/уведомлений/облака. Как перенести данные на новый телефон? → бэкап в облако (Pro) + восстановление. Что будет после триала? → демо (1 устройство). Как купить Pro? → Telegram-бот / почта. Почему ключ не подходит? → ключ привязан к androidId, на другом устройстве не сработает. Есть ли реклама? → нет. Собираете ли вы данные? → нет, см. политику.
