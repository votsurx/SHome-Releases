FAQ — Частые вопросы

Ответы на частые вопросы по SHome. Если не нашли ответ — напишите на votsurx@gmail.com.

Общие вопросы

Что такое SHome?

SHome — приложение для управления умным домом: Tuya, Zigbee (через Zigbee2MQTT), Frigate. Работает локально, без обязательного облака. Поддерживает сцены, таймеры, статистику, уведомления, presence, MQTT.

На каких платформах работает SHome?

Только Android 10+ (minSdk 29). iOS, Windows, macOS — не поддерживаются.

Где скачать SHome?

  • GitHub Releases (APK).
  • RuStore (скоро).

Бесплатно ли SHome?

Да, в демо-режиме — 1 устройство, бесплатно. Триал — 14 дней полного доступа. Pro — платно (ключ),1 год или бессрочно. См. Pro-лицензия.

Нужен ли интернет?

Нет, для базовой работы. Интернет нужен только для:

  • Проверки обновлений (опционально).
  • Уведомлений VK/SMS (опционально).
  • Облачных бэкапов (опционально).

Собираете ли вы мои данные?

Нет. Все данные хранятся локально. androidId используется только для привязки Pro-ключа. См. Политику конфиденциальности.

Tuya

Почему SHome не видит устройства Tuya?

  • Телефон и устройство в одной Wi-Fi сети?
  • localKey верный? (см. настройку Tuya)
  • IP-адрес устройства верный?
  • Firewall на роутере (порт 6668)?

Как получить localKey?

Через Tuya IoT Platform (Devices → Device Details → Local Key) или через tinytuya (см. настройку Tuya).

localKey не подходит

Перепривяжите устройство в Tuya Smart (удалить → добавить заново). После перепривязки localKey меняется — получите новый.

Устройство Tuya 3.4+ / 3.5 — поддерживается?

Да, SHome поддерживает Tuya 3.3, 3.4, 3.5 (через tinytuya). Проверьте версию протокола в Tuya IoT Platform.

Zigbee (Z2M)

SHome не видит Zigbee-устройства

  • Z2M запущен? (docker ps | grep zigbee2mqtt)
  • MQTT-настройки в SHome верные?
  • Z2M публикует топики? (zigbee2mqtt/bridge/devices)
  • Устройства сопряжены с Z2M? (Permit join)

Как установить Z2M?

См. настройку Zigbee2MQTT. Нужен координатор (CC2652, ConBee II, Sonoff Zigbee 3.0) + MQTT-брокер.

Устройства не сопрягаются

  • Permit join включён в Z2M?
  • Устройство в режиме сопряжения?
  • Устройство рядом с координатором?

Frigate

SHome не подключается к Frigate

  • URL верный? (http://your-server:5000)
  • Firewall (порт 5000)?
  • SHome (телефон) в той же сети, что Frigate?

Нет событий из Frigate

  • Веб-интерфейс Frigate (:5000) показывает события?
  • detect включён в config.yml?
  • Объекты (person, car) в кадре?

Как установить Frigate?

См. настройку Frigate. Нужен сервер (Raspberry Pi 4+, NUC, Synology), IP-камеры (RTSP), MQTT-брокер.

MQTT

Что такое MQTT и зачем он нужен?

MQTT — протокол обмена сообщениями. SHome использует его для связи с Zigbee2MQTT и Frigate. Нужен MQTT-брокер (Mosquitto). См. настройку MQTT.

«Connection refused»

  • Mosquitto запущен? (docker ps | grep mosquitto)
  • Порт 1883 открыт?
  • Firewall?

«Not authorized»

  • Пользователь создан? (mosquitto_passwd)
  • Пароль верный?
  • allow_anonymous false в конфиге?

Облако (Mail.ru)

«Неверный пароль» в облаке

Используйте пароль приложения Mail.ru (не основной). Создайте в id.mail.ru/security.

«Ошибка расшифровки»

Ключ шифрования не совпадает с тем, которым зашифрован бэкап. Импортируйте правильный QR-код. Если ключ потерян — бэкап невосстановим.

Как настроить облако?

См. настройку облака.

Уведомления (VK / SMS)

VK: «Не удалось отправить»

  • access_token истёк — получите новый.
  • user_id верный?
  • Приложение VK имеет права messages?

SMS: «Не удалось отправить»

  • API-ключ верный?
  • Баланс SMS.ru пополнен?
  • Номер в формате +79001234567?

Слишком много уведомлений

  • Увеличьте cooldown (10–30 мин).
  • Отключите лишние типы (например, «устройства»).
  • Включите расписание (ночь — тишина).

Как настроить уведомления?

См. настройку уведомлений.

Presence

Статус не меняется

  • Геолокация включена в Android?
  • Координаты «дома» верные?
  • Радиус достаточный? (увеличьте до 200 м).
  • Телефон отправляет координаты?

Батарея быстро садится

  • Уменьшите частоту обновления (10–15 мин).
  • Используйте Wi-Fi вместо GPS.
  • Отключите фоновый режим (если не нужен).

Pro-лицензия

Что даёт Pro?

Все функции SHome: неограниченные устройства, сцены, таймеры, статистика, Zigbee, Frigate, presence, уведомления, MQTT, облако. См. Pro-лицензия.

Как купить Pro?

Через Telegram-бот (скоро) или вручную (votsurx@gmail.com).

Как активировать ключ?

Настройки → Pro → «Активировать Pro» → ввести ключ.

Можно ли перенести Pro на другой телефон?

Лицензия привязана к отпечатку устройства. Для смены телефона обратитесь к разработчику или поддержке за переносом или перевыпуском лицензии.

Что если я потерял лицензию?

Если вы сохранили выданную строку лицензии, её можно повторно ввести на том же устройстве. Если строка утеряна, обратитесь к разработчику или поддержке с подтверждением покупки.

Можно ли использовать лицензию на нескольких устройствах?

Лицензия содержит отпечаток устройства и проверяется локально. Для другого телефона нужна лицензия, выпущенная для его кода запроса. По вопросу переноса обратитесь к разработчику или поддержке.

Что будет после триала?

Переход в демо-режим (1 устройство). Данные не удаляются. Активируйте Pro — всё вернётся.

Потерял ключ — что делать?

Если приложение удалено — ключ потерян. Обратитесь к продавцу с чеком об оплате.

Обновления

Как обновить SHome?

  • GitHub Releases: скачайте новый APK, установите поверх.
  • RuStore (скоро): автообновление.
  • В приложении: Настройки → «Проверить обновления».

Данные сохранятся при обновлении?

Да, при установке поверх (без удаления) данные сохраняются. При удалении — теряются (если нет бэкапа).

Проблемы и решения

Приложение падает

  • Обновите до последней версии.
  • Очистите кэш (Настройки Android → SHome → Очистить кэш).
  • Переустановите (с бэкапом!).
  • Версия android должна быть 10+.
  • Если не помогает — напишите на votsurx@gmail.com с описанием.

«Устройство offline»

  • Проверьте сеть (Wi-Fi, LAN).
  • Перезагрузите устройство.
  • Проверьте IP-адрес.

Данные пропали

  • Проверьте, не удаляли ли приложение.
  • Восстановите из бэкапа (облако).
  • Если бэкапа нет — данные не восстановить.

«Demo: only one device allowed»

Это ограничение демо-режима. Активируйте Pro (см. Pro-лицензия).
